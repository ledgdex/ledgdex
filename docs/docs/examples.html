EXAMPLES


Every example below is a file in guide/examples/, run as it is on every push: each must exit without error and print what its expect: lines name. Download one and run it in an empty folder (keys go to ~/.ledgdex, or set LEDGDEX_HOME to keep them apart).

Example: First Trade (everyone): A whole trade between a seller and a buyer on one machine: offer, claim, receipt, payment, delivery and confirmation, then verification.

Example: Marketplace (market operators): An operator's root and index, two shops selling to admitted members, a buyer choosing the cheapest offer through the index, and a stranger turned away.

Example: Auction (sellers and bidders): A sealed-bid auction with two bidders, their reveals, and the winner by rule.

Example: Disputes (buyers, sellers and arbiters): A dispute ruled by the arbiter the offer names, and a seller's own ruling ignored.

Example: Keys (everyone): A phone with a device key, revoking it, rotating the owner key, and recovering a lost key through the root.

Example: Publish (sellers): Publishing to a git repository from two devices, with the second catching up automatically.

Example: Check (everyone): A seller rewriting its ledger to erase a sale, caught by ledgdex check with signed proof, and the GitHub workflow that runs the check daily.

Example: Python API (developers): The core API without a dex: a ledger in memory, signed messages, verification, state, and a one-byte change caught.

Example: Bots (bots and developers): A seller bot and two buyer bots trading through an index to closed deals, with no person involved.

Example: Robot Cleaning (bots and machine operators): Robots of two operators paid per clean by the shops of a mall, one robot going offline mid-day, and the day's totals from the ledgers.

Example: Extending (developers): A sales report from the state, added to the dex as a page that ledgdex keeps.

Example: JavaScript (developers): The JavaScript core in Node (and the browser): a ledger made, read back from its bytes, and its state.

Smaller examples are on each topic page: Selling, Buying, Set Up a Marketplace, Checking for Tampering.
