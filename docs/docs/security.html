SECURITY


What ledgdex guarantees, and the trust that remains, in full: SECURITY.md. In short:

tampering is evident        any changed byte breaks verification at that line, in Python and the browser
rewrites are caught         ledgdex check keeps copies and follows receipts: signed proof of a rewrite
only a key's holder signs   strict Ed25519; keys never leave your machine (600 files, sealed in browsers)
messages count once         a signed message recorded twice is ignored
hostile ledgers are data    no script or link injection, no local file reads, size and depth limits

What you do: keep owner keys offline and backed up, use device keys day to day, install the fast extra where you sign, run ledgdex check daily, and report problems to the address in SECURITY.md before publishing them.
