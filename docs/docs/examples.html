EXAMPLES


Every example below is a file in guide/examples/, run as it is on every push: each must exit without error and print what its expect: lines name. Download one and run it in an empty folder (keys go to ~/.ledgdex, or set LEDGDEX_HOME to keep them apart).

Example: First Trade: One shop sells mangoes to one buyer, from start to finish, on your own computer.

Example: Marketplace: A small market: an organiser lets members in, lists two shops, and a member buys the cheaper mangoes.

Example: Auction: A gallery auctions an old map with secret bids, and the highest bid wins.

Example: Disputes: A buyer pays but gets nothing, complains, and an independent judge orders a refund.

Example: Keys: Keeping your ledger safe: a phone signs for the shop, the phone is lost, and a lost key is replaced.

Example: Publish: Putting a ledgdex online from two devices without the two ever disagreeing.

Example: Check: Catching a cheat: a shop secretly rewrites its records, and a check proves it.

Example: Python API: For developers: using ledgdex from Python directly, with no files or website.

Example: Bots: Programs trading with each other, with no person involved: two buyer bots buy software licences from the cheaper of two seller bots.

Example: Robot Cleaning: Cleaning robots paid per clean by the shops of a mall, for one day.

Example: Extending: For developers: building your own report from a ledger, and adding it to your website.

Example: JavaScript: For developers: the same ledger code in JavaScript, for Node or a web page.

Smaller examples are on each topic page: Selling, Buying, Set Up a Marketplace, Checking for Tampering.
