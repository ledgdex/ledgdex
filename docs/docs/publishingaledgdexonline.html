PUBLISHING A LEDGDEX ONLINE


A ledgdex is published like any dex, with dexweb: to a git repository (GitHub Pages for free hosting) or a folder. The difference: config.json has "append_only": ["ledgdex.jsonl"], so dexweb refuses to publish a ledger that does not extend the published one.

1. Make a repository (on GitHub: YOU.github.io, or any repository with Pages on).

2. Name it at init, or later in config.json "publish": 

ledgdex init shop --name "Mango Farm" --key farm --url https://YOU.github.io \
    --dest git@github.com:YOU/YOU.github.io.git --branch main

3. Publish after changes: 

ledgdex publish shop

4. Others read it at the address: 

ledgdex verify https://YOU.github.io

From several devices: each keeps a copy of the dex and its own device key. If another device published first, ledgdex publish re-signs this device's unpublished entries on top of the published ledger and publishes again: one history, never two entries at one position. Example: Publish runs it against a local repository.

Static hosting is enough: GitHub Pages, any web server, a shared folder on a local network (machines can trade over plain HTTP: Bots and Agents).
