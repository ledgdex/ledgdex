INSTALLATION


Ledgdex needs Python 3.8 or later and dexweb (installed with it). Publishing needs git.

1. From the release (recommended): 

pip install "ledgdex @ git+https://github.com/matrixdex/ledgdex@v1.0.16#subdirectory=py"

2. With fast, constant-time signing (recommended on every machine that signs; ledgdex warns without it): 

pip install "ledgdex[fast] @ git+https://github.com/matrixdex/ledgdex@v1.0.16#subdirectory=py"

3. From a clone, to develop: 

git clone https://github.com/matrixdex/ledgdex
cd ledgdex
pip install -e "py[fast]"
cd py && python -m unittest discover -s tests

4. Check: 

ledgdex --help
ledgdex verify https://matrixdex.github.io/ledgdex/docs

The JavaScript core needs no install: it is plain ES modules in js/, also served next to the viewer (API Reference).

Where things live: keys in ~/.ledgdex (or $LEDGDEX_HOME), the verification cache in ~/.cache/ledgdex (or $LEDGDEX_CACHE); see Configuration.
