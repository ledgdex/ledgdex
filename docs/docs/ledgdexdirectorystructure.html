LEDGDEX DIRECTORY STRUCTURE


What ledgdex init shop ... makes. Everything in the folder is public except nothing: keys are never in a dex.

shop/
  ledgdex.jsonl        the ledger: a header line and one signed entry per line (append-only)
  data.json            the dex pages: yours, and the ones ledgdex writes (they start with <!-- ledgdex -->)
  config.json          dexweb settings, "publish" (with "append_only": ["ledgdex.jsonl"]) and "ledgdex"
  styles.css           the look (dexweb's default)
  run.py               "python run.py" builds the dex with dexweb, as in any dex
  to_add/              files to add as pages (dexweb)
  backup/              dexweb's backup of data.json
  gen/                 the website: what is published, including gen/ledgdex.jsonl
  .ledgdex-root.jsonl  the last copy of the root read (only with a root; never published)
  .ledgdex.lock        one writer at a time
  .publish/            dexweb's copy of the repository it publishes to

~/.ledgdex/            secret keys, mode 600 (NAME.key), and secret bids until their reveal (bids/)
~/.cache/ledgdex/      which ledger bytes were already verified (a speed-up only)

Only gen/ is published. ledgdex render shop rewrites the generated pages and rebuilds gen/; every command that records does it for you.
