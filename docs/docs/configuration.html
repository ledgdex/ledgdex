CONFIGURATION


config.json is dexweb's, with two parts ledgdex reads:

{
  "dexname": "Mango Farm", ... dexweb's templates and settings ...,
  "publish": {"dest": "git@github.com:YOU/YOU.github.io.git", "branch": "main",
              "append_only": ["ledgdex.jsonl"]},
  "ledgdex": {"root": "https://market.example", "root_id": "sha256:..."}
}

publish: where dexweb publishes (dexweb docs); append_only must list ledgdex.jsonl. ledgdex: the root this dex trades under, pinned by its id.

Environment variables:

LEDGDEX_HOME       where keys live (default ~/.ledgdex)
LEDGDEX_CACHE      the verification cache (default ~/.cache/ledgdex)
LEDGDEX_NO_CACHE   1: verify every entry every time
LEDGDEX_PURE       1: sign and verify with the built-in Ed25519 (not constant time)
LEDGDEX_MAX_BYTES  the most read from one address (default 67108864, 64 MiB)
